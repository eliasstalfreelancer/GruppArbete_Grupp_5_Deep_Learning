# Upgift 
5. Data augmentation
Det här området handlar om att förändra träningsdatan för att förbättra modellens förmåga att generalisera.
Ni kan till exempel testa:
rotation av bilder
spegling (flip)
zoom eller små förskjutningar
Målet är att förstå hur mer varierad data kan göra modellen mer robust.
